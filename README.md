# Контроль сроков нарядов СУИСТ-1

Учебная демо-версия NOC-панели для дежурных ООУ.

## Возможности

- автоматический отбор нарядов со сроком на сегодня;
- поиск и фильтры;
- карточки исполнителей;
- имитация Telegram-уведомлений;
- действия дежурного и журнал контроля;
- расписание проверок по будням в 09:00 и 16:00.

Все данные являются демонстрационными. Подключения к реальной СУИСТ-1 нет.

## Локальный запуск

```bash
pnpm install
pnpm dev
```
